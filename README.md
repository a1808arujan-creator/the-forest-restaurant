# The Forest Restaurant Website

## About the Project

This project is a website about The Forest restaurant. It was created for the Introduction to Web Technologies course. The purpose of the project is to practise basic HTML and semantic page structure using information about a real local restaurant.

## Pages

The website contains 4 pages:

- **Home** (`index.html`) - introduces The Forest and provides general information about the restaurant.
- **Menu** (`menu.html`) - presents information about the restaurant's menu and dishes.
- **Contact** (`contact.html`) - contains contact information and a reservation form.
- **Colophon** (`colophon.html`) - explains how the website was created and describes some of the HTML elements used in the project.

## Technologies

The website was created using HTML5. No CSS, JavaScript, frameworks, templates, or website builders were used.

## How to Open the Website

Download or open the project folder and open `index.html` in a web browser. The navigation menu can be used to move between all four pages.
