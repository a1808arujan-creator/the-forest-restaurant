How i built this website

I created this website using HTML . The project contains four pages:Home,Menu,Contact,Colophon. I used semantic elements to make the structure of each pafe clear and easy to understand

For example, I used <header> for the header section, <nav> for the navigation menu, <main> for the main content area, and <footer> for the footer section. I also used <section> and <article> to group related content together.

HTML elements used

The menu page contains an HTML table with real menu items and prices from The Forest. The contact page includes a reservation form with a different input types,labels,radio buttons,a checkbox,a select menu and a textarea.

Development process

I worked on a project in Visual studio code. To save my chages,i used Ctrl + S keyboard shortcut. I used the live server extension to preview my changes in real time. I also used Git to keep a history of the project while i added new pages and features.

One example of a Git command i used is: 

git add .
git commit -m "Added Home page structure"

After a successful commit, Git shows onformation about the saved changes. An example of the output is: [main 1a2b3c4] Added Home page structure 1 file changed, 20 insertions(+)
