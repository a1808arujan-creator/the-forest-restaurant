How I Built This Website

I created this website using HTML. The project has four pages: Home, Menu, Contact and Colophon. I used semantic elements to make each page clear and easy to understand.

The project contains four HTML pages.

I used <header> for the top of each page, <nav> for navigation, <main> for the main content and <footer> for information at the bottom.

HTML Elements Used

The Menu page contains a table with real menu items and prices. The Contact page contains a reservation form with different input types.

Development Process

I worked on the project in Visual Studio Code. I used Ctrl + S to save changes and Live Server to preview the website. I also used Git to keep a history of my work.

Git commands used in the project:

git add .
            git commit -m "Add home page structure"

After a commit, Git shows information about the saved changes. For example: 1 file changed.

Project Notes

This website currently uses only HTML. CSS and JavaScript are not included in this assignment. The reservation form is not connected to a backend, so submitted data is not stored or sent to the restaurant.
